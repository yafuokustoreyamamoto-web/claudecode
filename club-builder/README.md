# CLUB BUILDER J

スマホのブラウザで遊べるサッカークラブ経営ゲーム。ホームタウンに新しいクラブを立ち上げ、J3からJ1の頂点を目指します。
3Dの試合画面はなく、試合は文字の実況で進みます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（GitHub Pages に置けばスマホからも開けます）。進行はブラウザに自動で保存されます。

- **プレシーズン**：スポンサー選び、契約更改、ユース昇格、キャンプ、スタッフ補強、移籍
- **シーズン**：「試合へ」で1節ずつ進む（全38節）。第4・10・16・24・30・36節のあとに天皇杯
- **昇格・降格**：上位3クラブが昇格、下位3クラブが降格。J2は収容1万人、J1は1万5千人のスタジアムが必要
- **経営**：入場料・グッズ・スポンサー・分配金・賞金で稼ぎ、年俸・施設維持費・移籍金を払う。シーズン終了時に資金が−3億円を下回ると解任
- **育成**：練習場・コーチ・練習方針・キャンプで選手が伸びる。31歳を過ぎると衰え、引退する
- **移籍**：国内の選手は検索して交渉。欧州の選手と海外組の日本人はスカウトを派遣して見つける。往年のレジェンドもフリーで現れる

## 選手データ

`data/FCRJ_選手データ.xlsx`（Jリーグ2273人、Jレジェンド433人、欧州4502人、欧州レジェンド273人、海外組の日本人94人）。
データを差し替えたら次のコマンドで `index.html` を作り直します。

```
pip install openpyxl
python3 tools/build.py
```

## ファイル

- `src/game.js` … ゲームロジック（試合・経営・移籍・育成・昇降格）
- `src/ui.js` … 画面
- `src/game.html` … 見た目（CSS）と外枠
- `tools/build.py` … xlsx を読み込み、上の3つと一緒に `index.html` にまとめる
